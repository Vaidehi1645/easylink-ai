📚 What this bot learned

    ⚙️ How it works

    • Paste a link → EasyLink crawls the site (public pages only, robots.txt respected, 20 pages max)
    • Index → every page is chunked and embedded, so answers retrieve in milliseconds
    • Ask anything → replies stream word by word, each claim linked to the exact page it came from
    • No source, no claim → if the site doesn't say it, the bot honestly says "I don't know"

    🧩 About EasyLink

    EasyLink turns any website into a grounded AI chatbot you can embed with a single script tag. The widget lives in Shadow DOM, so a host page's CSS can't break it (and it can't break the page back).

    Every answer is built only from what the site actually says: retrieval first, generation second, citations always. Questions the site can't answer are captured as gaps — a ranked to-do list of what to add next.
